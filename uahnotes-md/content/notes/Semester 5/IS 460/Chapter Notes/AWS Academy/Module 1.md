## Introduction to cloud computing

- **Cloud computing:** on-demand delivery of compute, storage, db, application,etc. and other IT resources over the internet with pay as you go pricing
  - Enables to stop thinking of infrastructure as hardware and think of it as software
    - Flexible
    - Can change more quickly, easily, cost-effectively than HW solutions
    - Eliminate undifferentiated heavy-lifting tasks
- **IaaS:** infrastructure as a service (Lowest IT resource control)
- **PaaS:** platform as a service
- **SaaS:** software as service (Highest IT control)
- Cloud computing deployment models
  - Cloud
  - Hybrid
  - On-premises (private cloud)

## Advantages of Cloud computing

- Trade Capital Expense for Variable Expense
  - Paying only for consumption of resources instead of attempting to allocate before deployment
  - Reduced maintenance
- Massive economies of Scale
  - Cheaper cost since AWS is a large provider
- Reduced Capacity uncertainty
  - Resources scale on demand
- Increased Agility and Speed
  - Less time required to provision and deploy resources
- No cost of running data center
- Easy global connectivity (lower latency)

## Introduction to AWS

- **Web service:** any piece of software that makes itself available over the internet using a standardized format
- AWS services work together - ecosystem of web services
- Can shut down AWS resources temporarily or permanently
- 3 ways to access: AWS management console, AWS CLI, SDKs
