## AWS pricing model

### Compute

- Charged per hour/second
- Varies by instance type

### Storage 

- Charged typically per GB

### Data transfer

- Outbound aggregated and charged
- Inbound normally has no charge
- Charged typically per GB

### Paying for AWS

- Pay for what you use
- Pay less when reserving
- Pay less when you use more and as AWS usage grow
- No long-term contracts required
- Tiered pricing for services like Amazon S3 - more used less cost per GB
- Multiple storage service deliver lower storage costs based on needs
- AWS sometimes lowers prices
- Can also request custom pricing
- Free tier products - might be charges with provisioning resources

### Total cost of ownership

- **Total Cost of Ownership:** financial estimate to help identify direct and indirect cost of system
- Can help build the case for switching to cloud infrastructure
- Considerations:
  - Server Costs
  - Storage Costs
  - Network Costs
  - IT labor costs
- Can use the AWS pricing calculator to estimate monthly costs, identify opportunities to reduce cost, name estimate and create groups of services
- AWS console can estimate console
- Reductions in operational costs, hardware and software, reduction in needed personnel

## AWS Organizations

- Allows to have a clear and defined report from a specific organization
- Free management service that can consolidate many departments or teams
- Branch of organizational chart can also contain other branches
- **IAM:** allow or deny access to AWS services for users, groups, roles, services
- **SCP:** Service control policy, enable you to allow or deny access to AWS services for individuals or groups
- Creating organizations:
  1. Create organization
  2. Create organizational 
  3. Create service control protocols
  4. Test restrictions
- Can be accessed via AWS management console, AWS CLI, SDKs, APIs

## AWS Billing

- Can set granularity of billing dashboard reporting
- Can be used to see trends in billing, cost, services, etc.
- AWS Budgets, AWS Cost and Usage Report, AWS Cost explorer

## AWS Support

- Proactive Guidance - Technical Account Manager
- Best practices - AWS trusted advisor
- Account assistance - AWS support concierge
- 4 stable plans:
  - Basic support - Resource center access, Service Health Dashboard, product FAQs, discussion forums, support for health checks. No case support
  - Developer support- early development support. 12-24 hours or less
  - Business support - Customers that run production workloads. 1-24 hours or less
  - Enterprise support - Enterprise support, customers that run business/critical workloads. 15 min-24 hours or less
